# Gridlytics

Smart Meter Intelligence & Loss Detection Platform — mock-based demo for BESCOM (Theme 8)

**Live demo:** https://gridlytics.vercel.app

This is a static frontend with pre-generated JSON snapshots under `/api/*`. No backend required.

## Deploy

Push to GitHub, then import into Vercel (Framework Preset: **Other**, Output Directory: `.`). The `vercel.json` config sets up static API routing automatically.
